Privacy Policy - Hubit!

Effective Date: September 5, 2026 | Last Updated: September 5, 2026

Summary: Hubit! is an offline-first, local network utility for Android TV. We do not collect, store, transmit, or sell personal data or file contents to external cloud servers. All file transfers, clipboard synchronization, and media management remain strictly on your local private Wi-Fi network.

1. Data Collection & Privacy

Hubit! does not collect personal identity data, telemetry logs, or location information. All network actions are initiated directly by the user on their own local Wi-Fi network.

2. Permissions

Hubit! requires Storage, Network, and Install Package permissions solely for downloading, browsing local files, hosting the local Web Bridge, and installing user-requested APK applications.
